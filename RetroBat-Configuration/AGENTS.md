# RetroBat configuration

Read ../AGENTS.md and README.md. This is a configuration workflow with original
shader-selection YAML and a read-only PE inspection tool, not an installer.
Keep third-party shader packs, ROMs, BIOS files and saves outside the repository.
Do not apply old display settings or rebuild save junctions during documentation.
Preserve Xbox label-matching controls and the uncommon rear-button chords.
